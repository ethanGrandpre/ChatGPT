Where do I get my token?
  1. Open GroupMe Developers and sign in to your own GroupMe account.
  2. Open Applications and create an application if needed.
  3. Copy “Your Access Token” and paste it above. If a callback URL is required, use this page’s address.

The token stays in your private server account. It isn’t saved in browser storage or returned to other Dock accounts. This connects your GroupMe API account; it does not collect your password.

Preview mode uses a separate demo connection. Your owner GroupMe account is never used here.
