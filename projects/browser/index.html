Dock Browser

A minimal browser for Mac, iPhone/iPad, and Android. Tabs, search, bookmarks, and light/dark mode, using each platform’s native web engine. This page is the project home; browsing runs in the installed app.

Desktop

The native macOS build opens websites in WKWebView, with separate tabs, navigation controls, saved bookmarks, and a responsive toolbar.

Successful GitHub builds provide a Mac app archive. The development app is unsigned and not notarized.

Mobile

The same app targets Android and iPhone/iPad with a compact toolbar and native web rendering. Android builds provide a test APK.

iPhone installation requires Xcode, Apple signing, and a connected device. No iOS install package is available here yet.

Build status

Open “View builds & downloads” to check the latest run. Downloadable files appear in its Artifacts section only after a successful build. This project page does not imply that a native build has finished.

First version

Includes tabs, address/search, back/forward, reload/stop, loading feedback, bookmarks, and saved themes. Downloads, extensions, password management, private mode, and cross-device sync are future work.
