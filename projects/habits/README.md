# Habits
Run opens a daily habit tracker with a Monday–Sunday calendar, check-ins, current streaks, renaming, deletion Undo, and JSON backup merging. Future days cannot be checked. Dates use local calendar arithmetic (including daylight-saving transitions); a streak survives an unfinished today until tomorrow. No model or API key is needed. Data lives in `dock-habits-v1` in the browser and syncs through the private Dock workspace while signed in. Import merges checked dates by habit ID without replacing existing names or removing other habits. Limits: 50 habits, 100-character names, 2 MB import.
