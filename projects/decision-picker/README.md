# Decision Picker
A local equal-chance picker for low-stakes decisions. One option per line; duplicates collapse, up to 200 unique options. Uses `crypto.getRandomValues` with rejection sampling to avoid modulo bias. Optional chosen-option removal and a 20-pick history with clear Undo. Imports unfinished task titles from this browser's `dock-tasks-v1` without editing tasks. Lists and history are saved in `dock-decision-picker-v1`; plain-text list export is available. Project data syncs through the private Dock workspace while signed in; no model or API key is needed. Reduced motion is respected.
