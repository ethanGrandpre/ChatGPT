GroupMe Messages

Read your GroupMe groups and direct conversations, and send group messages from Dock. The open conversation and group badges check for new messages while this page is visible. Open Settings to choose a refresh interval from 1 to 300 seconds.

Run GroupMe Messages →

One connection setting

  1. Open GroupMe Developers → Applications → your application.
  2. Click Copy beside Your Access Token.
  3. In Cloudflare → Workers & Pages → chatgpt → Settings → Variables and Secrets, save it as a Secret named GROUPME_ACCESS_TOKEN. Deploy the settings.
  4. Run this project and choose Connect / refresh.

If you already saved that secret, leave it in place. No Client ID or callback authorization is needed.

Messages stay in GroupMe and are fetched on demand. Your token stays on the server. Unsent drafts and quoted reply previews stay in this browser tab for up to 24 hours; message history is fetched on demand. Use the Groups and DMs tabs for existing conversations. DMs are read-only because GroupMe does not make DM sending available through its Developer API. Shared images and videos from GroupMe’s media hosts appear inline in groups and DMs. Tap Play to load a video; images load lazily. Direct attachment links remain available if playback or a preview fails. Other attachment types can be opened separately. Group messages have reactions confirmed by GroupMe, quoted replies, and a Delete button for your own recent messages. GroupMe may restrict actions. The reaction picker offers the 15 emoji described in current community API documentation. Success requires confirmation from GroupMe; unrestricted emoji are not supported. Editing sent messages is not implemented: a supported Developer API endpoint could not be verified. Starting a new DM and SMS are not included.

Make it yours

Settings includes text size, compact spacing, simple message rows, and conversation width. These preferences and group read counts sync through your private Dock account. Number badges show new group messages since you last viewed the latest messages here. The first visit establishes a baseline; reading in the official GroupMe app does not update Dock badges.

Find searches the messages currently loaded in a conversation. Load earlier messages to search more. Drafts stay separate for each group when you switch conversations. If new messages arrive while you are reading older history, Jump to latest takes you back without losing your place automatically.

Real group typing events show an animated three-dot indicator at the bottom of the chat. Indicators disappear after a few seconds without a new event. The connection pauses when the chat is hidden; connection details show its status. This does not broadcast your typing or provide DM typing indicators.

Chat notifications

Open device notification settings with the bell button and enable each phone or computer once. Then switch Notify on at the top of the chats you want. Chat choices apply to all enabled devices. Server checks run about every 30 seconds while the page is closed; browser and OS settings can delay delivery.

Notification previews are stored privately in Cloudflare until acknowledged or for up to 24 hours. They can appear on the lock screen. If your Dock sign-in expires, a generic notification opens the sign-in page. You can test delivery from device notification settings.
